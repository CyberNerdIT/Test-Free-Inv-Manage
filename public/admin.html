API integrations
eBay API
Used for live active-listing comps (Browse API). Recently-sold comps need Marketplace Insights approval. Get keys at developer.ebay.com.
Amazon API
Product Advertising API v5 (SearchItems). Requires an approved Amazon Associates account. Amazon provides active offers only (no sold history).
Notification integrations
Connect the services used to send purchase alerts and emails. Turn each one on for notifications under Notifications.
Email (SMTP)
Used for password‑reset, welcome and stock-alert emails, plus the Email notification channel. Gmail needs an App Password. Purchase alerts go to your admin email (⚙ Account menu).
WhatsApp
From the WhatsApp Business Cloud API: an access token, your phone-number ID, and the number to alert. Business-initiated messages must use a pre-approved template — plain text only delivers within 24h of the recipient last messaging you, so template mode is the default. hello_world is pre-approved on every account and works immediately for testing; create your own template with a {{1}} body variable to include the request details. The token on Meta's API Setup page expires after 24h; the Pro bundle ships pro/docs/whatsapp.md with the steps for a permanent one.
Discord
Server Settings → Integrations → Webhooks → copy the Webhook URL.
Telegram
Create a bot with @BotFather for the token; get your chat ID from @userinfobot.
Pricing defaults
Applied to break-even and suggested-price math when an item doesn't override them.
Notifications
Purchase alerts
Turn on the connected channels that should ping you when a customer requests to purchase. Requests are always saved under “Purchase requests” even with everything off. Connect a channel under API integrations.
Welcome email (waitlist approval)
Sent when you approve a waitlist signup. It carries their invite link. Placeholders: {{name}}, {{link}} (invite URL), {{brand}}.

Password reset email
The HTML emailed to a user when they request a password reset. Placeholders: {{name}}, {{username}}, {{link}} (the reset URL).

Site & branding
Branding
Rename the app and its tagline — shown on the landing, login and storefront pages. Handy if you fork/share the project.
The landing page always carries a “Want to host your own?” link to the open-source project. This build is that project, so the link stays.
Colour scheme
Applies everywhere — this admin portal, the inventory app, the customer storefront and the public landing page. Each scheme ships a matching light and dark palette.
Custom colours Pro
Setting every colour individually is part of the Pro upgrade, which this build does not include.
Website link
Shows a link to your site on the landing page and the customer storefront.
Landing deals
The “savings” cards on the public landing page. Add a manual illustrative card, or pick a real inventory item to advertise — a linked card pulls the item's live title, price and photo and disappears automatically once it sells. Leave “Was” blank to hide the savings badge.
Storefront
Condition definitions
“Refurbished” means different things to different sellers. Your own sentence appears on the item page — one honest line builds more trust than a badge does. Leave any blank to hide it.
Shopper options
Community directory off
Your region
Used only to answer “is this shop near me?”. Deliberately coarse — no street, no postcode beyond a district prefix, no coordinates, and never guessed from your IP address.
How shops find each other
Shared listings
Tick “Share with the Tech Garage community” on an item to publish it. A listing is delisted automatically when it sells, is hidden, or you untick it.
Nearby shops on your storefront
Connect with another shop
Send a friend your link, and open theirs to connect back. Connected shops always rank above strangers, and are the only ones shown if you turn on “only shops I've invited”.
